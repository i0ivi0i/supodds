# 赛后复盘（post-review）

获取已完场比赛的结果，对比推荐记录，计算命中率，分析失误原因，更新长期统计。

**术语**：`OO-EPC` = Goto (2026) 欧指等利润去水概率（市场映射，不是最终预测）；`布莱尔分` = Brier score；`CORP` = Dimitriadis 概率校准/可靠性分解，含 `MCB`（误校准）、`DSC`（区分度）、`UNC`（固有不确定性）；`认知契约卡` = 赛前冻结的选择排除/关键拍板/庄家假说/反证条件；`三端` = 胜/平/负；`探针` = EvoOntology 的只读校验查询。

## 论文应用回检

每场复盘至少引用 **1 句原文**（文件名 + 原句）；没有论文锚点的教训不得写入 `MEMORY.md` 永久条目。完整论文触发表、回检动作与原文边界见 `references/01-论文与庄家复盘.md`。
**读取门**：进入步骤 4 前必须读取 `references/01-论文与庄家复盘.md`，并留下 `loaded_ref: 01` 回执；未读停线。

## 闭环验收（处理完成与方法证据分开）

逐项按真实证据标已核、缺失或待办，不预填全勾。分别保存「处理状态」「方法证据」「投递状态」：可恢复的抓取、核对或写入尚未做完，记「仍有待办/执行失败」；全部可执行核对已做且仅永久缺失赛前资料，记「已完成但部分指标不可评分」，列出缺失及影响，不无限重跑，也不称完整方法验证。资料齐备且全部核对通过才记「已完成」。已知答案标事后审计，不能补成盲审；证据不足不能升级永久规则，但不抹掉已核实的首选结果。

## 执行步骤

### 步骤 1：读取推荐记录

从每日记忆中获取需要复盘的推荐。**若 `memory/{复盘日期}.md` 不存在**，视为无推荐记录，直接执行下方「如果没有找到推荐记录」的后续逻辑（告知主人、写入 ## 赛后复盘、结束）。

```
read_file(path="memory/{复盘日期}.md")
```

找到推荐部分：在 memory 文件中查找所有**二级标题**为以下之一的 section：

- `## 推荐`
- `## 推荐（*)`（\* 为时间，如 14:25）

旧记录沿用原口径；`paper-application-v2` 按matchId取每场开球前最后有效发布并匹配其分析版本，早批未刷新的场次不丢失。已知赛果后的补写不得覆盖赛前首选、概率。研究统计按 `matchId+发布版本+指标` 去重更新，补赛果不能重复累加。

**全量推演场次 1:1 提取（杜绝免责候补池）**：

- **当期开售全部 N 场推演场次**：逐一提取联赛、主队、客队、首选/次选、让球推荐、信心度、比赛 ID 及赛前契约卡；全量场次 100% 纳入复盘对账主盘与累计统计分母，严禁设立“候补免责池”。

- **赛前漏推与虚假推演（无工具轨迹）红线报警**：若赛程索引（`meta.md`）中存在但赛前未做深度推演、缺失契约卡封存，或者**赛前执行轨迹（transcript）中缺失真实的 EvoOntology 官方 MCP 调用记录（`start_ontology_task` ➔ 1 次 `browse_semantics` + 5 批次 `resolve_ontology_task` ➔ `finish_ontology_task`）**的场次，复盘报告**必须置顶输出红色高危警报**：
  `> [!CAUTION] 🚨 赛前推演漏场红线报警：发现当期开售场次 {编号} {主队} vs {客队} (ID: {matchId}) 赛前未推演或缺失官方工具调用轨迹！`
  表格中强制标注为 `[赛前未推演/不可评分]`，严禁赛后反向脑补预测或冒领命中，并锁定漏场责任记录入事故日志。此类场次不计入推荐总数与命中率计算。

**复盘对账主体 = 当期全部开售场次（N 场全量核销）**：严格贯彻 1:1 闭环 Poka-Yoke 铁律，所有开售场次必须 100% 逐一进行【胜负平】与【让球】双列核销对账，进入累计推荐统计大盘。严禁区分精选组与候补组，杜绝双重账本。逐场表覆盖全部当期 `matchId`，统一核销首选命中与双选覆盖。
- **初即盘口与流水基准核查**：核查赛前底层存证 `data/{销售日}/{matchId}.db` 的 `亚盘`/`亚盘变盘`/`大小球`/`大小球变盘`/`欧指变盘`，确认初盘让球门槛（如半球、一球、球半/两球）与即盘位移；人类简报 `.md` 仅作可选看板交叉核对，绝不作为唯一物理基准。以此作为赛后让球打出（✅/❌/走水）与庄家诱盘破译判定的唯一物理基准。

**补追待复盘场次**：检查前 3 天（{复盘日期-1} 到 {复盘日期-3}）的 memory 文件，如果其中有标记为「待复盘」的场次，一并纳入本次复盘。这些场次：

- 在复盘报告中标注为「补复盘（原推荐日期：{日期}）」
- 命中率计入原推荐日的统计；更新 MEMORY.md 累计值时合并入原推荐日贡献即可，**同步更新原日该场待办状态、最终结果和补盘记录位置，其他场次保持不变；原日统计贡献由同一写入者按新值替换，不能在两天重复入账**
- 命中率和泊松 Top 6 校验正常计算

如果没有找到推荐记录（当日 + 待复盘均无）：

- 告知主人「{日期}没有推荐记录，无需复盘」
- **仍须在 `memory/{复盘日期}.md` 中追加写入**（若文件不存在则创建）：
  ```
  ## 赛后复盘
  {日期} 无推荐记录，无需复盘。
  ```
  以便 Heartbeat 不再重复触发复盘补漏。
- 结束流程（不执行步骤 2–9，不更新 MEMORY.md）

### 步骤 1.5：先审过程，再揭比分（Aiyer 决策审计与认知契约卡前置布尔核验）

取赛果之前，只读当日 `## 深度分析` 与推荐理由（三维落槌、关键点、疑点、矛盾，**特别是赛前冻结的「图谱认知基因」与「认知契约卡」**）。**先列当期全部 `matchId`（共 N 场），逐场提取赛前冻结的认知基因与认知契约卡（选择与排除依据、关键拍板依据、庄家博弈假说与竞争解释、可推翻反证与改变条件），写两行并保存可回读的过程审计记录，之后才调用抓取赛果**；严禁遗漏任何一场，严禁只审局部场次，也不能把事后写在赛果前面的章节冒充“先审”。若某场赛前缺失契约卡，直接在过程审计中判定为【赛前契约卡缺失 / 违规漏推】。已在先前对话、日志或来源中看到赛果的场次标「已知答案的事后审计」，不得宣称严格先审后揭。每场：

- 过程：当时胜/平/负三端是否写清「为何出/不出」；证据是否打架；**赛前调用的图谱武器（节点 ID）与当场盘赔特征是否匹配自洽**；认知契约卡中排除最高概率项或选择次选的依据是否充分。
- **认知契约卡反证条件前置布尔核验（硬门禁）**：
  提取赛前契约卡中第 ④ 项【可推翻反证与改变条件】，逐字对照赛前终盘赔率走势与数据，强制输出明确的布尔判定：
  `【反证触发判定】：[未触发] / [已触发（注明时间戳与具体走势）]`
  - **红线惩罚**：若赛前设定的反证条件（例如“若临盘平博主胜跌破 1.80 则主胜假设证伪”）在终盘前已明确出现，但赛前推演未果断执行降级或熔断，无论最终赛果是否蒙对，本场在揭比分前必须直接定性为【过程违规 / 执拗死扛】，坚决剥夺其“推演成功”评价（Aiyer 2023）！
- 待揭晓：还不知道赛果，不打命中分

取完赛果后，过程分保持不动，另写结果分。禁止用赛果改写「当时其实已经看出来」。对账验真规则：
1. **若首选命中**：简要对账即可，记录为符合赛前判断的样本；不吹捧因果链绝对有效，不把单场猜对等同于庄家底牌被完全破译；
2. **若首选未命中（打出次选或失误）**：重点逐项深挖赛前抉择理由，强制调出赛前冻结的决策摘要与认知契约卡，启动决策归因审计：
   - **重点核查项**：
     - ① 当时选择该项、排除打出项的核心事实与盘赔特征，哪一条在赛前就存在主观偏见、解读过当或信息遗漏？
     - ② 当时支持庄家诱盘或阻盘的假设，是否存在更合理的竞争解释在赛前被轻视或忽略？
     - ③ 可推翻反证中列出的条件，在赛前终盘是否其实已经出现苗头但未果断降级或观望？
   - **严禁借口推脱**：严禁以赛中偶发事件（如最后绝杀、偷袭、红牌、摆大巴）作为失误理由；也不得仅因赛前提过该风险，就声称过程必然合规。
3. **自进化靶向改进**：根据上述倒查出的赛前认知缺陷，提炼明确的待验证改进假设（注明适用场景、改变的证据规则与对应论文方法），记入长期记忆待验证池；遵循分级自治机制，经过后续同场样本检验达标后再行采用，严禁草率把单场失误升格为全局死规则。

### 步骤 3：逐场核对

对每场推荐的比赛：

1. **匹配比赛**：通过主客队名在赛果列表中找到对应比赛
2. **获取比分**：记录最终比分（如 2:1）
3. **判断命中**：

**胜平负**：

| 推荐类型               | 命中判断规则                                                                                                                                                         |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 固定 2 项（首选+次选） | 推荐为 首选 + 次选。**核心首选命中**：实际赛果与首选完全一致才算首选命中。**双选覆盖命中（风控备选参考）**：首选或次选任一命中即为覆盖命中（其中仅次选命中属于备选覆盖，不得把覆盖命中冒充核心首选命中）。赛果判定：主胜=主队进球>客队，平局=主队=客队，客胜=客队进球>主队。 |

**亚盘完整规则**：

设净胜球 = 主队进球 - 客队进球，盘口 H = 主队让球数（正值主让，负值主受让）。调整后净胜球 D = 净胜球 - H。

| 盘口类型     | 举例                | 上盘（让球方）结算 | 走水       | 下盘（受让方）结算 |
| ------------ | ------------------- | ---------------- | ---------- | ---------------- |
| 整数盘       | -1, 0, +1           | D > 0 赢         | D = 0      | D < 0 赢         |
| 半球盘       | -0.5, -1.5, +0.5    | D > 0 赢         | 不可能走水 | D < 0 赢         |
| 四分之一球盘 | -0.75, -1.25, +0.25 | 拆两注，见下方规则 | 一注走水时按赢半/输半 | 拆两注，见下方规则 |

**四分之一球盘详细规则**（-0.75 = 半球/一球, -1.25 = 一球/球半, +0.25 = 平手/半球 等）：

- 将盘口拆为两注：H₁ = H - 0.25, H₂ = H + 0.25
- 分别按整数/半球盘规则判定两注的输赢
- **全赢**：两注都赢 → 命中
- **赢半**：一注赢 + 一注走水 → 命中（半），统计计 0.5 场命中
- **输半**：一注输 + 一注走水 → 未中（半），统计计 0.5 场未中
- **全输**：两注都输 → 未中

**大小球完整规则**：

设总进球 T = 主队进球 + 客队进球。

| 盘口类型     | 举例       | 大球赢                         | 走水     | 小球赢   |
| ------------ | ---------- | ------------------------------ | -------- | -------- |
| 半数盘       | 2.5, 3.5   | T > 盘口                       | 不可能   | T < 盘口 |
| 整数盘       | 2, 3       | T > 盘口                       | T = 盘口 | T < 盘口 |
| 四分之一数盘 | 2.25, 2.75 | 拆两注，按整数/半球盘结算：全大/赢半 | 一注走水时按赢半/输半 | 拆两注：全小/输半 |

**大小球首选/次选（新口径）**：

- 若推荐记录中大小球写为「首选 …；次选 …」：
  - **严格命中（用于统计）**：只判定**首选**是否命中（次选不计入命中率分子分母，仅用于覆盖展示）。
  - **覆盖命中（用于风控评估）**：首选或次选任一命中则记为覆盖命中（可在逐场报告里单独写一行，不计入主命中率）。
- 若推荐记录中大小球仅有单一方向（旧记录）：按旧规则直接判定该方向命中即可。

4. **标记结果**：命中 / 未中 / 走水 / 赢半 / 输半

**走水和半赢半输场次的统计规则**：

- **走水**：不计入命中率（分子分母均排除），复盘报告中单独列出「⏸ 走水 N 场」
- **赢半**：分子 +0.5，分母 +1
- **输半**：分子 +0，分母 +1
- 命中率 = (全赢场次 + 赢半场次×0.5) / (总推荐 - 走水场次)

5. **组合推荐处理**：如果是组合推荐（如「主胜 + 大2.5球」），按玩法拆分分别判断命中，计入**各玩法命中率**（玩法类型：胜平负、亚盘、大小球、进球数；让球推荐计入亚盘）；旧版在"推荐场次"维度仍算1场，任一玩法命中按旧口径保留；新研究各玩法独立评价，不用其他玩法命中替代胜平负首选命中。**标注「⚠️ 观望」的玩法**：该场在该玩法上不计入推荐数、不计入命中数（分子分母均排除），与 recommendation 的「多玩法统计规则」一致。
6. **比分预测核对**：将实际比分与推荐比分对比（泊松相关比分最多 6 个）
   - 完全命中其中一个 → 标记 🎯 精准命中
   - 未命中但总进球数一致 → 标记「进球数正确」
   - 完全不中 → 标记「比分未中」

- 从当日 memory 读取**赛前实际发布版本**的「独立泊松比分简表」，只检查实际比分是否落在其 Top 6；不再读取或要求完整 0:0～7:7 概率表。若缺 λ/Top 6，记「赛前未记录／不可评分」，不能赛后按比分补算当成赛前预测。
- **两套比分增强**：若该场在 ## 深度分析 中存在「与大小球同方向 Top 3」——即当时有大小球 vs 泊松矛盾、存了两套比分——则分别检查实际比分是否命中「整体 Top 3」或「同方向 Top 3」，用于对比矛盾场次的方向选择。

7. **串关核对**：从当日 memory 读取串关组合建议，逐个组合判断
   - **2 串 1**：两场推荐都命中 → 串关命中；任一未中 → 串关未中
   - **3 串 1**：三场推荐全部命中 → 串关命中；任一未中 → 串关未中
   - 比分串关：两场比分都精准命中 → 串关命中
   - 混合串关（如 1 场比分 + 1 场胜平负）：各自按对应规则判断，全部命中才算串关命中
   - 记录每个组合的预期赔率和实际结果

### 步骤 3.5：分析质量自评（泊松模型质量）

用以下指标评估比分模型质量：

- **Top 6 命中**：实际比分是否出现在泊松比分简表 Top 6 中？
  - 记录实际比分在Top4、Top6之内或之外，保留检查λ的线索；单场排名不独自判模型优秀或失效
- **λ 偏差方向**：记录实际总进球与预期总进球（λ1+λ2）的差；累计同类样本再判断系统性偏高或偏低
- **两套比分场次**：若该场深度分析中存在「与大小球同方向 Top 3」，在逐场输出中写「整体 Top3 命中/未中；同方向 Top3 命中/未中」，便于长期对比两套策略

### 步骤 3.6：概率打分（有数才算，不当对错本）

命中率只说明猜中没猜中。有赛前主胜/平/客胜三个概率时，另算布莱尔分（Wheatcroft）：

- 打出哪项，那项记 1，其余记 0
- 分数 = (主概率−主实际)² + (平概率−平实际)² + (客概率−客实际)²，越低越好
- 三个概率须是赛前已留的点概率，在0到1且合计1（声明舍入误差）。只有区间就记「缺赛前点概率」，不在赛后取中点造数；方向命中与推演过程仍正常复盘。市场、独立泊松、综合判断分源评分。回查各自方法、原始批次与实际输出：比例归一不能记成 OO-EPC；未执行 OO-EPC 只评实际留存的方法，不从固定表头推定算法已运行。
- **没有三个概率就写「无概率，只记命中」**，不许编数字
- 首选命中与布莱尔分分开写，不得用「首选+次选任一算中」代替概率分

**Dimitriadis (2021) CORP 布莱尔分三项数学分解与思维链诊断**：
采用 Dimitriadis et al. (PNAS 2021) 的 CORP 评分分解（将 Brier 型分解推广到 proper scoring rule；经典 Brier 分解源于 Murphy 1973），布莱尔分可分解为：
$$\text{Brier} = \text{MCB} - \text{DSC} + \text{UNC}$$
大模型在复盘打分时，必须在脑内思维链执行三项分解定性与半定量诊断，并在报告中扼要体现：
1. **$\text{MCB}$（Miscalibration，误校准偏差）**：赛前概率与客观实际发生率之间的系统性距离。例如赛前给出 30% 平局概率，若在长期大样本中该概率区间的平局发生率确实稳定在 30% 左右，则 $\text{MCB} \approx 0$（校准近乎完美）。**【绝对禁止刻舟求剑】单场推平分出胜负绝不代表平局预测失败！30% 概率本就意味着 70% 的大概率分出胜负，单场未出完全符合泊松正态方差，绝对严禁因单场未出平局就草率否定平局模型或进行惩罚性降权！**
2. **$\text{DSC}$（Discrimination，区分辨别能力）**：模型在不同事件发生时拉开概率差距的能力（即“看得清局势”还是“和稀泥”）。三端概率越能精准区分两队实力差距（如 65%/22%/13% 对比 35%/33%/32%）且高概率项与赛果方向一致，$\text{DSC}$ 越大，总布莱尔分越低（预测越优秀）；
3. **$\text{UNC}$（Uncertainty，环境固有不确定性）**：足球比赛固有的最大熵与随机性（先验发生率的内生方差）。不可通过调参消除，只能通过大样本平滑。

新研究记录另列首选命中、双选覆盖、观望数和缺概率数，不改旧累计口径。可加对数损失 `-ln(实际结果的赛前概率)`，零概率而发生时为无穷，不偷偷裁剪；Wheatcroft并非证明布莱尔唯一最优。比分提取、概率打分与命中率对账 100% 由大模型依据本技能规约在思维链中端到端自主计算，严禁编写任何临时脚本或工具代码。Dimitriadis用于定期比较主／平／客概率和实际频率，校准拟合用过去、评价用以后，不拿单场兑现与否否定概率。
