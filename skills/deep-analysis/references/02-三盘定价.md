- **亚洲联赛**：澳彩(1)、皇冠(3)、365(8)、易胜博(12)、马会(48) **5 家交叉认证**（4 家 + 马会）。

**去水无偏概率工具与 Goto (2021) 概率定位解绑（强制调用）**：核算分析依据公司的真实无偏概率与抽水率时，必须调用官方 sports-math MCP 工具：`devig_oo_epc(home_odds=..., draw_odds=..., away_odds=...)` 获取客观标准点概率，严禁大模型主观心算或凭空捏造。
- **Goto 学术定位解绑**：明确 OO-EPC 仅仅是当前赔率盘面所对应的“市场即时无偏概率映射”，**绝对不等于做市商对真实赛果的终极预测**！当做市商设局诱多时，即时报价本身就是引流诱饵；终审决策由三端博弈产生，绝对严禁倒果为因、盲目将 OO-EPC 最高概率项直接当成最终推荐。
- **Levitt (2004) 客场热门与 Minimax 净赔付审计**：对客场声名显赫的热门队伍（Visiting Favorites），反问做市商若打出是否会造成净赔付击穿；若做市商在临盘以更高赔率持续出让筹码（客水飙升或客赔暴涨），优先定性为做市商利用散户盲从偏见进行非对称高位出货，真实净赔付防线必在主队不败！严禁使用“抬高做阻”、“退盘保护强队”等反向找补套话；阵容主力伤停必须足额扣减，严禁以“豪门板凳深度厚”为由豁免或稀释物理事实！

**执行顺序**：先完成本步下方的「欧指赔率变动轨迹分析」（时点对齐 + 每家意图 + 相同时点认证 + 一句话解读），再用下列第一～五层对初盘、即时盘及轨迹结论做系统排查与交叉认证。

**状态空间审查（直接读取 EvoOntology 全量时序，不在本技能生成展示表）**：以时间戳为唯一顺序，直接审查初盘起点、日内极值拐点与最新定格盘；极值与位移写入时序分析证据，不在本技能排版原始数据表。

**状态空间审查维度（以数值变动幅度与关口突破为第一核心）**：
- **初盘起点基准**：衡量做市商未受注额冲击前的初始物理基准数值；初盘数值提供重要的长期定价锚点；
- **极值拐点（Inflection Point $t_{inflect}$）**：时序演进中出现的赔率极值数值（如 1.85 诱客极限低位）；
- **数值位移量（Numerical Displacement $\Delta$）**：审查从极值点或初盘到即时终盘的真实数值位移（如 1.85 ➔ 2.15，大幅逆转位移 +0.30）；重中之重是看数值变动幅度（$\Delta \ge 0.15$ 为结构性大位移）与关键关口击穿，严禁以时间长短武断定性，若某公司全程无调整填「无变动」。

**分析思路（教学级排查流程）**：

**第一层：初盘合理性判断** — 赔率与实力是否匹配？

- 强队主胜应偏低（<2.00），弱队客胜应偏高（>3.00）
- 如果不匹配，排查原因：伤停？轮换？战意？交锋克制？
- **平局赔率的博弈心法（Andrikogiannopoulou 2011 & Levitt 2004 泄洪阀）**：平赔高低须结合该联赛天然进球环境（如法乙天然偏低、德甲天然偏高）与初即相对位移（$\Delta_{draw}$）判定：相对联赛基准受压收紧提示避险，持续抬升提示分流（严禁一票排除）
- 初盘/即时盘与实力是否匹配、与**本场欧指分析依据公司**（主流巨头交叉认证、欧陆/意系参考、亚洲 5 家）共识是否一致，据此判断诱/错盘。

**第二层：变动排查** — **只要赔率有变化，都必须判断原因**

**主胜、平局、客胜三项都要逐项填排查清单**，不能只写主胜。若平赔有单独、反向变动（如主胜降但平赔明显升），在每家意图或一句话解读里点出（如「平赔抬升提示平局风险降低」或「平赔走低需警惕平局」）。

欧指赔率绝对值较大，幅度可参考：**小幅 ≤0.05**（约 2～3%）、**中幅 0.05～0.15**、**大幅 >0.15**（约 7%+）；不要与亚盘水位幅度混用。

每一项赔率变动（主胜/平/客胜）逐一排查三种可能：

1. **平衡筹码（被动调整）**：某一结果投注量过大，机构降低该项赔率平衡资金
   - 特征：变动幅度小（0.02-0.05），方向与大众热门一致
   - 例：热门主队大量投注 → 主胜赔率小幅下降 → 正常平衡
2. **机构主动调整（有信息驱动）**：机构基于信息改变判断
   - 特征：变动幅度大（>0.10），或与大众情绪相反
   - 例：主队热门但主胜赔率反升 → 机构不看好主队，有利空信息
3. **诱买操作**：引导散户买某一结果，实际看好其他结果
   - **形态识别（强制触发，高危信号）**：当出现 **“欧指与亚盘反向变动”** 且同时伴随 **“水位异常/阀值触发/盘水矛盾”**（如亚盘主水持续打穿 ≤0.80 或 ≥1.05、或升盘升水/降盘降水这类矛盾组合），不得直接一刀切定性为诱买；但必须**强制**执行以下动作：
     1. 在第 7 步与第 9 步将其列为**高权重疑点/核心矛盾**；单场信心度应下调
     2. 启用「矛盾裁决规则（让球防守底线优先于欧指表面宣传口号）」，以亚盘净胜球防守底线为主裁决、欧指作为“散户引流/诱买风控”保留；仍须三端写清，不得单凭单一盘口定生死
     3. 在下列三类中做**分流定性**（择其一，写清理由）：**诱买** / **风控阻热（控量控赔付）** / **真实信息驱动（基本面可解释）**
   - **分流判断要点（写在一句话解读或第 7/9 步）**：
     - **更像诱买**：欧指在热门方向“给甜头/造利好”（例如热门主胜赔率明显走低、或平赔阀门配合），但亚盘持续阻热门（不升盘/退盘/抬热门水），且临场加剧
     - **更像风控阻热**：亚盘极端水位主要用于“堵注/控赔付”，欧指并未明显喂热门（甚至热门赔率反升），且存在先动者→跟随者的风控轨迹
     - **更像真实信息驱动**：有可核验的基本面利空/结构性因素（关键伤停、战意、轮换、赛程陷阱等）能解释亚盘与欧指的错位
   - 例：欧指降主胜（大众更想买主）但亚盘不升盘甚至降盘 + 主水持续走高/打穿阀值 → **高危信号**：优先按“亚盘阻热”为主裁决，并在三类中分流（可能是诱买，也可能是风控阻热）。

**排查清单（每项赔率变动都要过一遍）**：

```
变动项：{主胜 / 平局 / 客胜}
变动方向：{升(看衰) / 降(看好)}
变动幅度：{小幅(≤0.05) / 中幅(0.05-0.15) / 大幅(>0.15)}
与大众情绪：{同向(可能平衡) / 反向(可能机构主动)}
与亚盘方向是否一致：{一致(信号可靠) / 矛盾(疑似诱买)}
能否用基本面解释：{能 / 不能(暗盘信号)}
→ 结论：{平衡筹码 / 机构主动看好X / 诱买X}
```

**第三层：RLM（逆向线路移动）检测**

RLM（逆向线路移动）是识破庄家非对称收割与暗中防范的关键信号：

- **判断大众情绪方向**：热门球队（豪门、连胜队、高排名队）= 大众倾向买的一方
- **观察赔率实际走向**：赔率往哪边移动？
- **两者是否反向**：大众买主胜 → 但主胜赔率反而上升（变贵了）= RLM 信号
- RLM 意味着有**尖锐资金在押另一边**，机构跟着尖锐资金走而不是跟着大众走
- 一旦检测到 RLM，**在第 7 步标记为高权重信号**
- **与诱买区分**：RLM 只说明「赔率与大众反向」；需结合第二层判断是**机构主动看好另一边**（真信号）还是**诱买**（刻意抬价引导买主胜等）。结论在第 7 步写清，避免 RLM 与诱买混为一谈。

```
RLM 检测清单：
大众情绪方向：{买主胜 / 买客胜}（根据球队热度判断）
赔率实际走向：{主胜降(看好) / 主胜升(看衰)}
是否反向：{是(RLM!) / 否(正常)}
→ 如果是 RLM：尖锐资金方向 = {与大众相反的一方}；再结合第二层判断：机构主动 / 诱买
```

**欧指赔率变动轨迹分析（必做）**

使用步骤 1 过验【推演源数据】的**本场欧指必抓与重点公司的完整赛前变动历史**（欧洲非德国赛事 = 威廉、365、立博、伟德、平博等主流及重点参考公司；德国联赛 = 威廉、365、Interwetten 三家；亚洲联赛 = 澳彩、皇冠、365、易胜博、马会 5 家）。**参与轨迹分析的公司 = 本场欧指重点公司**，机构字段按实际提取结果。目标：看各公司在**相同时点**如何变动、是否达成共识，并判断庄家意图（平衡/主动/诱买等）。

1. **构建时点对齐与时间先后因果链**
   **时点格式与时间自检规则**（第 4/5/6 步欧指、亚盘、大小球通用）：
   - ⏰ **时间基准自检与倒计时阶段测算**：推演第 0 步必须自查【推演源数据】头部的 `- **开球时间**：YYYY-MM-DD HH:mm`（$T_{kickoff}$）。对各流水行中的 `变盘时间 MM-DD HH:mm`，大模型自主比对开球倒计时 $\Delta T = T_{kickoff} - t$ 映射做市阶段：
   - 🔒 **第 0 步物理锁定**：七表边界、22 家核销、7 家变盘、波胆与防脑补规则见 `01` 的 1.2~1.5；本步不重复，只保留欧指时点对齐与初终差值。
     - 时间最早点（$\min(t)$，最早开盘记录）➔ **① 初盘骨架 (起点 $t_0$)**：无大众注额冲击下的初始物理基准；
     - 比赛日早晨（$12\text{h} \le \Delta T < 24\text{h}$）➔ **② 早盘试水**：做市商消化隔夜新闻/初步注额的微调；
     - 赛前数小时（$2\text{h} \le \Delta T < 12\text{h}$）➔ **③ 中盘博弈**：散户与主力博弈期，高发 Winkelmann 假摔 (Head-Fake) 震仓；
     - 首发确认前后（$30\text{m} \le \Delta T < 2\text{h}$）➔ **④ 临盘洗盘**：真实首发出炉与大单撞击，做市商极限挤压水位；
     - 封盘前夕最新点（$\max(t)$ 且 $< T_{\text{kickoff}}$）➔ **⑤ 终盘关门 (终点 $t_{\text{latest}}$)**：最后资金出清防守，做市商不可撤销的结算底线。
   - ⚠️ **时间戳绝对排序与因果演进铁律（杜绝排版刻舟求剑）**：无论源数据按何种排版呈现，本技能必须按物理时间戳升序排序（`Sort by Timestamp ASC`）建立时间流，在时间流中标注「①初盘起点 ➔ ⑤终盘关门」因果编号。
   - 🔍 **全程三维时空折返门禁（通过 EvoOntology 官方工具提取，严防中盘诱骗）**：推演前必须通过 EvoOntology 官方 MCP 全量提取变盘流水，输出三大时空坐标：
     * **起点时空（时间最早点 $\min(t)$）**：抄录【变盘时间】（如 `09-11 05:49`）与【盘口/水位】；
     * **过程极值点（中盘 $t_{\text{ext}}$）**：提取中盘最高峰值（$P_{\max}$）或最低谷值（$P_{\min}$）及其时间戳；
     * **终点时空（时间最新点 $\max(t)$）**：抄录【变盘时间】（如 `10-14 12:03`）与【最新盘口/水位】；
     * **双段动态位移与峰值暴跌破译（Winkelmann 2026 & Goto 2026）**：
       1. **初终净位移**：$\Delta_{\text{total}} = t_{end} - t_0$；
       2. **峰值暴跌量**：$\Delta_{\text{crash}} = t_{end} - P_{\max}$（从中盘最高点到终盘的真实打压幅度）；
       3. **警惕初终持平假象（中盘脉冲孤立凸峰）**：若初终位移接近于 0，但中盘存在显著逆向凸峰而后断崖暴跌，本质属于做市商利用中盘情绪诱空震仓、临盘暴力砸盘锁死筹码的极度真防，绝不可当成“毫无变化的一潭死水”；
       4. **严格区分「瞬态脉冲折返（真设防）」与「持久阶梯位移（真弃守）」（以终盘是否回踩初盘防线为准）**：
          - **瞬态脉冲折返（假摔真防）**：初盘基准 $t_0 \to$ 中盘冲高 $P_{\max} \to$ 终盘闭合归位 $t_{end}$。终盘完全回踩甚至跌破初盘基准防线（$t_{end} \le t_0$），中盘冲高判定为做市商制造的瞬态流动性诱空震仓（Winkelmann 2026）；
          - **持久阶梯位移（高位弃守）**：初盘基准 $t_0 \to$ 中盘冲高 $P_{\max} \to$ 终盘高位定格 $t_{end}$。终盘未能回踩初盘防线且滞留大幅升水高位（$t_{end} \gg t_0$），无论较中盘峰值技术回撤多少，全盘性质依然是不可逆的基本面定价重估与彻底弃守，触发硬熔断，严禁首选让球方！
   - ⚠️ **时间先后因果链（后动因前动而生）**：大模型推演思维必须**以物理时间戳最早的初盘起点 $\min(t)$ 起步，顺着时间流向按因果关系（从早到晚，从初盘到最新定格盘）顺流推演，严禁依赖任何表格行号位置**！严禁孤立看待单点变动！每一次变盘必须阐明：从上一时刻到当前时刻历经多少时间（$\Delta t$）、发生了何种做市动作、是对上一阶段何种市场反馈的应对、是否改变或强化了防守意图（$t_0 \to t_1 \to t_2 \to t_3 \to t_{end}$）。
   - 📐 **初终显式代数差值门禁（$\Delta = \text{即时} - \text{初盘}$）**：推演前必须先调取【欧指初即全景大表】，显式手算初终净位移；同时**严禁只看欧指初即大表抄近道**，必须穿透做市商变盘时序全量流水，结合亚盘与大小球跨市场几何张力（Constantinou 2022）交叉印证真伪！
     * 主胜 $\Delta_{\text{主}} = \text{即时主胜} - \text{初盘主胜}$；客胜 $\Delta_{\text{客}} = \text{即时客胜} - \text{初盘客胜}$；
     * 符号铁律：$\Delta < 0$ 为绝对降赔（机构设防、热度升温）；$\Delta > 0$ 为绝对升赔（机构弃守、筹码出让）；
     * **反做阻弃守硬熔断（Anti-Resistance Iron Law）**：当让球方 $\Delta \ge +0.20$ 且平博、365、皇冠同步升赔时，严禁使用“抬高做阻”、“假摔震仓”等套话，强制 100% 判定为庄家弃守，绝对严禁首选让球方独赢！

**第一块：从初盘分析盘口类型**（用初盘、变盘时序与阵容伤停）

本步**不与自开盘交叉**，仅**主流初盘 vs 基本面**；阶段 0 只做赛程索引，不做自开盘或盘口预判。相同初盘历史胜率、近 10 场盘路与半场双盘按设计不采集，不编造；只可用初盘、变盘时序与阵容伤停执行 **Tversky 小数定律与 Gilovich 热手偏见审计**，测算散户跟风买点，并识别全场与半场的盘口背离与诱买。分析逻辑：**基本面 → 本场应有盘口判断（隐含）→ 与主流初盘对比 → 盘口类型**。依据仅限**七表可见的盘赔与阵容伤停**，不假设有排名、往绩、战意或赛程字段。

**步骤**：根据基本面判断「本场按实力/情境应有的盘口大致是什么」→ 用主流初盘（澳彩、皇冠、365、易胜博、平博）与之对比 → 定性**盘口类型**与**错盘形态**，并在第 9 步提炼为关键点/疑点。

**盘口类型**（初盘定性，必选其一并写明）：

| 类型     | 定义                                | 操作含义                                                                                             |
| -------- | ----------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **实盘** | 4 家初盘与实力差/基本面匹配         | 合理开盘，重点看后续水位与变动是否阻/诱                                                              |
| **错盘** | 初盘即偏离实力/情境                 | 需进一步判错盘形态（见下）                                                                           |
| **深盘** | 初盘强于实力差（强让），或主让≥1 球 | 深盘局胜平负参考价值低，重点看亚盘赢盘/大小球/比分；强让+上盘高水=典型诱上，强让+上盘低水=真看好上盘 |
| **浅盘** | 初盘弱于实力差（浅让）              | 再判属下列三种之一：                                                                                 |

**浅盘三种**（浅盘时必过一遍）：

- **开盘偏浅**：初盘就比实力差弱。先排查核心出场权重/战意/赛程；能解释 → 正常让少；**解释不了 → 非对称偏见做市诱饵（Levitt 2004 & Kaunitz 2017）**，利用浅盘极低门槛吸引大众筹码涌入，实际净赔付防线在受让方。
- **浅上加浅**：本来就让得少，初盘→即时再降盘或水位继续不利上盘 → 机构明显不看好上盘，**偏反方向**（送钱给下盘一方）。
- **浅盘阻上**：盘口已经浅，还配合升水/阻上 → 「这么浅还诱我买上？」= **诱上盘**，实际多看好下盘或不看好上盘赢盘。

**错盘形态**（当判为错盘或强让/浅让有特殊情境时选用）：

- **错位盘**：实力差与盘口之间明显错位，无法用伤停/战意解释。
- **强让盘/强上盘**：强让上盘，常为诱上；结合水位判断诱上还是真看好。
- **名气盘**：借豪门/名气开深或开浅，盘口与真实实力差错位。
- **生死盘**：保级/出线等战意极端，盘口易失真，需结合战意判断。
- **Levitt (2004) 平手均势盘“送便宜诱主”**：主队初盘让球，临盘退至平手盘且给主队 $\le 0.84$ 低水（如 0.82）。散户心理贪图“主队主场打平走水保本”，做市商借主场名气降门槛送便宜引流散户买主。必须反查平博主胜变盘：若平博主胜升幅 $\ge +0.10$（如 2.29➔2.40），直接判定主不胜（客不败或客胜）。

**深盘局**：主让≥1 球时，胜平负参考价值低，重点看亚盘赢盘/大小球/比分。

**第二块：盘口与水位组合**（初盘→即时的变动，必过一遍）

在初盘类型明确后，看主流做市商从初盘到即时的**盘口变动 + 水位变动**组合，判断阻/诱、机构主动或平衡：

| 组合                        | 常见解读                                                                                             |
| --------------------------- | ---------------------------------------------------------------------------------------------------- |
| **降盘 + 升水**             | 机构彻底弃守上盘（Constantinou 2022 & Levitt 2004 Minimax）：门槛退缩且水位抬升，重心坚决在下盘      |
| **升盘 + 降水**             | 机构看好上盘：盘口进、上盘水还压 → 真看好上盘，或诱上（需结合 4 家是否一致）                         |
| **升盘 + 升水**（升盘升水） | 矛盾：盘进、上盘水反升 → **疑似诱上**（升盘吸注，升水实为不看好上盘），重点标出                      |
| **降盘 + 降水**（降盘降水） | 陷阱：退盘降门槛、配低水送便宜 → 典型散户倾倒筹码局（Levitt 2004），防范受让方独赢收割，严禁脑补为看好上盘 |
| **仅水位变、盘不变**        | 主水升=若单边持续升高为送水弃守，仅低位微调为试探；主水压低且盘口坚挺为真实控赔设防                  |

- **盘口档位**：平手 → 平半 → 半球 → 半一 → 一球 → 一球/球半 …（升盘=往右进一档，降盘=往左退一档）。
- **客让时**：上盘=客队；主水=客队水位、客水=主队水位，「阻上/放上」等对调理解。
- **走水/输半**：主让整球且净胜恰好等于让球数才走水；主让平半遇平输半，主让半球遇平全输。竞彩让平另按三项结算；这里修正的是结算，不改变诱阻推演方向。

**第三块：变动排查与水位信号**

**只要盘口或水位有变化，都必须给出原因判断**。亚盘看水位绝对值变动（如 0.02～0.05、>0.08），与欧指幅度不可混用。

每次变动三种可能：**平衡筹码**（变动小、与大众同向） / **机构主动调整**（变动大或与大众反向，最有价值） / **诱盘操作**（盘口与水位方向矛盾）。排查清单：变动内容、幅度、时间、与大众情绪、盘水是否矛盾、能否用基本面解释 → 结论。

**水位博弈心法（Kaunitz 2017 & Winkelmann 2026 赔付敞口杠杆）**：主水持续抬升（$\Delta > 0$）扩大赔付支出，属于做市商送水弃守，严禁机械脑补“升水做阻”；主水持续压低（$\Delta < 0$）且盘口坚挺，方为做市商真实控赔设防。与「盘口与水位组合」配合使用。

**第五块：主流做市商交叉认证 + 与欧指交叉验证与 Constantinou (2022) 优位性**

- 主流做市商是否同盘口、同方向 → 共识强。1 家与其余不一致 → **严格警惕冷门**，在第 7 步重点分析。2 家以上不一致 → 重大分歧，在第 7 步重点分析原因。
- **与欧指交叉验证与 Constantinou (2022) 二元连续市场优位性与双盘自洽硬契约**：
  - **AH 二元账本优位**：亚洲让球盘抽水低、容纳真实聪明钱主力对冲，是做市商的真实防守底线；而欧洲指数（1X2）是三元离散市场，散户情绪浓厚、做市商操盘引流空间极大。
  - **Constantinou 双盘自洽硬互斥契约（Anti-Contradiction Hard-Lock）**：凡在让球推演中判定受让方守住门槛（如 `[+1] 让胜` 或 `[+2] 让胜`，即受让方不败）时，胜平负绝对严禁落槌给让球方独赢！后台亚盘让球防守底线对前台胜平负拥有最高一票裁决权，胜平负必须顺从让球方不胜的物理底线（首选平局或受让方胜）。若前台胜平负推让球方独赢、后台让球推受让方不败，判定为严重双盘分裂认知病灶，必须硬锁修正！
  - **前后台自洽性思维直觉**：以亚盘水位真实流向（如科莫客水 0.88 ➔ 1.02 满水）作为欧指真实意图的“试金石”。一致则信号可靠；若欧指看好主胜但亚盘让球偏浅或降盘/主水抬升，标出矛盾，在第 7 步重点分析。

⚠️ **重要原则（必须写进结论）**：

- **做市商一致 ≠ 正路**：各家同盘口同方向只能说明“市场表达一致”，不代表方向真实；也可能是**同一操盘手法一致**（引诱/阻挡/控赔付）导致结果一致。
- 交叉认证的目标不是“找一致”，而是判断：一致是**自然收敛**，还是**协同风控/协同引导**。

本块输出**缺一不可**：

1. **一致事实**：盘口是否一致 / 水位是否一致 / 轨迹是否一致（是否齐步走 or 有先动者）
2. **阀值触发**：是否出现极端水位并持续（见下“阀值触发”）
3. **一致性质评分**：按评分规则给出「一致可信 / 一致存疑 / 一致危险」

**主流做市商一致的“操盘手法一致”识别（亚盘专用）**

把一致拆成三类一致并逐条核对：

- **盘口一致**：同盘位（如均为 主让平/半）
- **水位一致**：同区间（如主水都在 0.86～0.94）
- **轨迹一致**：是否“同一时间同方向”（齐步走）或存在**先动者**（一两家先动，其余跟随）

**阀值触发（疑似引诱/阻挡）**：

- 若热门方向一侧水位在赛前阶段长时间落在 **≤0.80** 或 **≥1.05**，且主流做市商同时如此（或在关键时点齐步打穿），视为“阀值触发”。结论里必须写清：**打穿哪侧、持续多久、盘是否配合升/降**。
- **盘不动但水位打穿阀值**为强信号：热门方水位一路升到 ≥1.05 甚至退盘 → 明确为庄家因风险敞口过大而放弃防守（弃守）；热门方水位压到 ≤0.80 且盘口坚挺 → 方为真实控制赔付。严禁对退盘或升水方套用“反向保护/做阻”等双标套话。必须结合欧指/大小球验真。

**一致性质评分（必须给分）**：

- **+2**：存在明确“先动者→跟随者”，不是多家同一时刻齐步走
- **+2**：初盘与基本面“应然盘口”匹配（实盘），且轨迹可解释
- **+1**：水位主要落在 0.82～1.00（未触发阀值）
- **+1**：欧指同方向配合且无明显反常（尤其平赔阀门）
- **-2**：主流做市商在关键时点“同一时刻同方向”齐步走（疑协同风控/引导）
- **-2**：水位打穿阀值且盘位不配合（强阻挡/强引诱形态）
- **-1**：与大小球/欧指组合难以解释（故事讲不通）

评分解释：

- **≥+3：一致可信（更像自然收敛）**
- **-1～+2：一致但存疑（更像风控/引导，需保守）**
- **≤-2：一致危险（统一操盘/错盘概率高，建议观望或反向审视）**

2. **每家意图小结**：对每家公司的整段变动给出结论（平衡筹码/机构主动/诱盘/阻上/拉上等，如澳彩中盘升盘高水诱多、终盘回踩低水控赔真防）。
3. **相同时点交叉认证**：分析各做市商在相同时点是否同盘口、同方向（升/降主水、升/退盘），若有分歧单独标出。
4. **一句话解读（必输出）**：一句话概括亚盘做市全周期变动含义（如「做市商中盘升盘升水假摔诱多，终盘回退半球 0.82 低水真防主胜」）。

**本步输出检查**：□ 时点对齐 □ 每家意图小结 □ 相同时点交叉认证 □ 一句话解读（缺一不可，便于自检与抽检）

#### 第 6 步：进球数赔率分析

数据来源：步骤 1 过验【推演源数据】的各公司大小球变化。

**执行顺序**：**先**用两队进攻/防守基本面与主流初盘做「从初盘分析盘口类型」→ **再**做「大小球赔率变动轨迹分析」（时点对齐 + 每家意图 + 相同时点认证 + 一句话解读）→ **再**用「盘口与水位组合」及变动排查、与基本面交叉验证、RLM、主流做市商交叉认证对初盘→即时结论做系统梳理。

**核心**：同第 5 步法定 7 家全能做市商；平博作低抽水锐度锚点，全权参与大小球印证。机构名单不重复。

**大小球数据不在本技能排版**：直接从 EvoOntology 读取法定 7 家的初盘、即时盘与大/小球水位；所有机构数值进入时序分析与本步结论，不生成展示表。机构方向结论统一用「正常 / 阻大 / 诱大 / 阻小 / 诱小 / 看大 / 看小 / 异常」标注，写入分析证据。

---

**第一块：从初盘分析盘口类型**（用两队进攻/防守基本面 + 各公司初盘）

本步**不与自开盘交叉**，仅**主流初盘 vs 基本面**。分析逻辑：**基本面 → 本场预期总进球/合理盘口判断（隐含）→ 与主流初盘对比 → 盘口类型**。依据仅限**两队进攻/防守基本面**（主客场场均进球、近期得失球、伤停对进攻的影响、战术风格、天气等）与**主流初盘盘口**（2.5、3、2/2.5 等）。

**步骤**：根据基本面判断「本场预期总进球大致是多少、对应合理盘口」→ 用主流初盘与之对比 → 定性**盘口类型**，并在第 9 步需要时提炼为关键点/疑点。

**盘口类型**（初盘定性，必选其一并写明）：

| 类型       | 定义                            | 操作含义                                                                    |
| ---------- | ------------------------------- | --------------------------------------------------------------------------- |
| **合理盘** | 4 家初盘与预期总进球/基本面匹配 | 重点看后续水位与变动是否阻大/阻小/诱大/诱小                                 |
| **开大**   | 初盘高于预期总进球（盘口偏大）  | 高盘口+大球高水=诱大；高盘口+大球低水=真看大                                |
| **开小**   | 初盘低于预期总进球（盘口偏小）  | 排查战术风格/核心缺阵出场权重；结合伤情时效（Macri 2025），防范借滞后伤停故意开小诱小球 |

**错盘/特殊形态**（需要时选用）：无明显原因盘口明显偏离预期 → 暗盘信号；生死战/极端战意导致盘口失真 → 需结合战意与基本面。

**大小球赔率变动轨迹分析（必做）**

使用步骤 1 过验【推演源数据】的**法定 7 家做市商（澳彩、皇冠、365、易胜博、平博、188、香港马会）完整赛前大小球变动历史**。参与轨迹分析的机构字段按实际提取结果。目标：相同时点是否同盘口、同方向；每家轨迹意图（平衡/主动看大(小)/诱大(小)球）。平博作为低抽水锐度锚点全权参与大小球走势与阻诱印证。
> 时序读取、初终盘判定与第 4 步相同；对象换成大小球盘口与大/小球水位。升盘=盘口变大，降盘=盘口变小。

1. **时点对齐**：主流做市商按时间对齐全量真实变盘节点（时点格式与升序时间流同第 4 步规范，涵盖 ①初盘起点 ➔ ⑤终盘关门），严禁人为抽稀。
2. **每家意图小结**：对每家公司的整段变动给出结论（阻大/阻小/诱大/诱小/主动看大/看小等）。
3. **相同时点交叉认证**：分析各做市商在相同时点是否同盘口、大球水/小球水是否同向。
4. **一句话解读（必输出）**：一句话概括大小球变动含义（如「做市商维持 2.5 球，大球水位抬升，一致阻大看小」）。

**本步输出检查**：□ 时点对齐 □ 每家意图小结 □ 相同时点交叉认证 □ 一句话解读（缺一不可，便于自检与抽检）

---

**第二块：盘口与水位组合**（初盘→即时的变动，必过一遍）

在初盘类型明确后，看主流做市商从初盘到即时的**盘口变动 + 大球/小球水位**组合，判断阻大/阻小、机构主动或平衡：

| 组合                           | 常见解读                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------- |
| **升盘（盘口变大）+ 大球水升** | 矛盾：盘变大、大球水反升 → **疑似诱大**（升盘吸注大球，升水实为不看好大球），重点标出 |
| **升盘 + 大球水降**            | 机构看好大球：盘口进、大球水压 → 真看大，或诱小（需结合 4 家是否一致）                |
| **降盘（盘口变小）+ 大球水升** | 矛盾：盘变小、大球水反升 → 可能诱小或平衡后仍略看好大球，需结合初盘类型与 4 家共识    |
| **降盘 + 大球水降**            | 盘退门槛降低、大球水位受压，做市商主动收紧大球赔付敞口（控赔防大球）                  |
| **仅水位变、盘不变**           | 大球水升（扩大赔付）=出让筹码送便宜（看小球/诱大）；大球水降（收紧赔付）=真实控赔设防（看大球） |

- **盘口档位**：升盘 = 盘口变大（如 2.5→3）；降盘 = 盘口变小（如 2.5→2/2.5）。

---

**第三块：变动排查与基本面交叉验证**

**只要盘口或水位有变化，都必须给出原因判断**。大小球看水位绝对值变动（如 ≤0.05、>0.08），与欧指幅度不可混用。

每次变动三种可能：**平衡筹码**（变动小、与热门方同向）/ **机构主动调整**（变动大或盘口直接升降，最有价值）/ **诱盘操作**（盘口与水位方向矛盾）。排查清单：变动内容、幅度、能否用基本面解释、盘口与水位是否矛盾 → 结论。

**与基本面交叉验证**：

- 两队攻强守弱 + 盘口却偏低 → 矛盾，可能诱小球
- 两队防守型 + 盘口偏高 → 矛盾，可能诱大球
- 核心射手伤停 + 盘口降低 → 需核实出场率权重与公布时效；若早已公开内化，警惕做市商临盘借题发挥诱小球（Macri 2025）
- 无明显原因但盘口大幅变动 → 暗盘信号

---

**第四块：RLM 检测**

- 大众倾向买大球（进攻型强队比赛）→ 但盘口降低或大球水位升高 = RLM 信号。
- 一旦检测到，在第 7 步标记为高权重信号。
- **与诱盘区分**：RLM 只说明「与大众反向」；需结合变动排查判断是**机构主动看小**（真信号）还是**诱大球**（刻意做盘），结论在第 7 步写清。

---

**第五块：主流做市商交叉认证 + 与欧指/亚盘交叉验证**

- 主流做市商是否同盘口、同方向 → 共识强。1 家与其余不一致 → **严格警惕冷门**，在第 7 步重点分析。2 家以上不一致 → 重大分歧，在第 7 步重点分析原因。
- **与欧指/亚盘交叉验证**：大小球结论与第 4 步欧指、第 5 步亚盘方向对比。若欧指偏大比分、亚盘偏进攻，但大小球降盘看小，标出矛盾，在第 7 步三种赔率交叉验证中重点分析。

⚠️ **重要原则**：同第 5 步「做市商一致 ≠ 正路」；大小球更常见控量/控赔付，盘口不动但水位长期极端或临场齐步打穿阀值时，按第 5 步评分标准处理。

本块输出**缺一不可**：

1. **一致事实**：盘口是否一致 / 大小球水位是否一致 / 轨迹是否一致（是否齐步走 or 有先动者）
2. **阀值触发**：是否出现极端水位并持续（见下“阀值触发”）
3. **一致性质评分**：按评分规则给出「一致可信 / 一致存疑 / 一致危险」

大小球做市商一致性核验与性质评分（盘口一致/水位一致/轨迹齐步走，阈值 ≤0.80 或 ≥1.05 触发）完全遵循第 5 步统一标准与评分解释（≥+3可信，-1~+2存疑，≤-2危险），不重复冗余定义。
